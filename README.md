# チャッとZPT

「現代人の語彙力の低下が、昔のLLM（大規模言語モデル）の挙動に似ている」という気付きを表現したインタラクティブアート作品です。
LLMを一切使わず、「やばい」「エモい」などの限られた語彙パーツをランダムに組み合わせて返答するAIチャットアプリ風の静的Webアプリとして構築されています。

私たちが日常的に頼りがちな「やばい」「エモい」といった万能な言葉を「代替トークン」として捉え、それに依存しきった不完全なコミュニケーションをあえて体験させることで、現代における語彙力の低下について問いかけます。

## 生成の仕組み (Z-トークン・メカニズム)

本アプリケーションは、背後に実際のLLM（大規模言語モデル）を一切持っていません。代わりに、独自の**「Z-トークン（Z-token）」生成アルゴリズム**によって応答を組み立てています。

1. スコアリングによるキーワード抽出: 
   ユーザーの入力から助詞やストップワード（「これ」「それ」「ます」「です」等）を除外し、残った単語に対して「文字数」「文字種（漢字・カタカナ・英数字の有無）」「出現位置」に基づくスコアリングを行い、最も重要度の高い1単語（最大18文字）をキーワードとして抽出します。

2. Z-トークン辞書からのランダム選択:
   「やばい」「エモい」といった限られた語彙パーツ（Z-トークン）は、「オープナー（導入）」「コア（核となる単語）」「リアクション」「エンディング（結び）」「キーワード言及」の5つのカテゴリに分類されています。ここから2〜5個のトークンをランダムに選択します。

3. コンテキストに応じた文脈の付与:
   - 最初のトークンには、抽出したキーワードを埋め込んだ専用のZ-トークン（例：「〇〇の話、マジやばいし」）が優先して選ばれることがあります。
   - ユーザーの入力が疑問符（「?」や「？」）で終わる場合は、応答の途中に「マジやばい」を挿入し、適当に相槌を打つ挙動を再現しています。

4. ストリーミング出力の模倣: 
   抽出したキーワードとZ-トークンの配列を組み合わせ、本物のLLMが文字を出力するようにトークンごとにランダムな遅延をかけながら順次表示します（「考え中...」のステータス表示もランダムな時間でシミュレートされます）。
